# PHL HealthGrid

PHL HealthGrid is an interactive map for finding healthcare facilities in Philadelphia. Search by name, street, or ZIP code and filter by facility type, services, or ownership. Select a location to see its details and open directions in Google Maps.

The Tract Demographics page shows how population, age, health insurance coverage, vehicle access, and SEPTA travel time to primary care vary across the city. Select a census tract on the map to compare it with the median among populated Philadelphia tracts.
